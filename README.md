# Repaso de Python para Data Science

Práctica introductoria de manejo de variables, listas, diccionarios y
funciones en Python, como paso previo a librerías como Pandas o Scikit-Learn.

## Contenido
- Tarea 1: Variables y f-strings
- Tarea 2: Bucle + condicional sobre una lista de precios
- Tarea 3: Diccionario simulando un almacén
- Tarea 4: Función que devuelve un resumen estadístico
